Développement et diagnostic · sensible

Copie privée pour test

Conserve les données, l’identité graphique et les PIN dérivés. Neutralise WordPress, Discord, SMTP, la météo et les tâches externes. Les connexions externes restent bloquées après restauration. La clé de session est renouvelée.

Les données personnelles restent présentes : cette copie doit rester privée, comme une sauvegarde complète.

Remplacement de l’installation

Restaurer une sauvegarde complète ou une copie de test

Vérification du format, des empreintes et de SQLite avant remplacement. Une sauvegarde complète de sécurité est conservée dans restore-backups. Les données ne sont pas fusionnées. Après restauration, reconnectez-vous avec le PIN de l’archive.
